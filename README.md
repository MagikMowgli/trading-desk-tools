# Trading Desk Tools

A collection of small tools designed to simulate real-world trading desk workflows, including trade investigation, PnL calculation, and data validation.

## Features
- Query trade data from PostgreSQL
- Investigate trades by ID
- Calculate PnL
- Detect anomalies

## Tech Stack
- Python
- PostgreSQL
- SQL

## Purpose
This project is designed to replicate tasks performed by trading desk engineers, including automation, data analysis, and debugging trade-related issues.
